# Career Quest — Flower Power

Прототип навигатора развития сотрудников для HackAlem AI, трек Halyk Bank.
Помогает связать требования карьерной цели, навыки и историю участия с конкретными шагами развития.

## Текущая реализация

- Импорт JSON/CSV в схеме стартового датасета версии 1.0; валидация ссылок и полей.
- Загрузка дополнительных профилей и истории жюри с проверкой конфликтов.
- Учёт завершённых активностей после последней оценки навыков.
- До трёх рекомендаций с объяснением: критические навыки, дефициты, история участия и формат работы.
- Исключение обязательных событий, проверка аудитории, предварительных требований и доступных сессий.
- Моделирование завершения с правилами `gain`/`max_level`, защита от повторного начисления.
- Поддержка повторных сессий клуба `EV_036`, экспорт состояния в четыре файла внутри ZIP.
- Собственный синтетический демонабор и тесты. Данные организаторов в Git не включены.

**Рекомендации сейчас расчётные, без LLM.** AI-провайдер и модель ещё не подключены.
Веб-интерфейс находится в разработке в этой ветке. Авторизации и постоянной базы данных пока нет.

## Установка и проверка

Нужны Git и [uv](https://docs.astral.sh/uv/getting-started/installation/). Python 3.12 закреплён в проекте.

```bash
git clone https://github.com/BAITC-Hacks/hack-ce23e8c4-flower-power.git
cd hack-ce23e8c4-flower-power
git switch feat/career-quest-mvp
uv sync --locked
uv run ruff format --check .
uv run ruff check .
uv run mypy .
uv run pytest -q
```

Стартовый набор можно локально поместить в `data/local/`: `employees.json`, `events.json`,
`skills.json`, `activity_history.csv`. Каталог исключён из Git.
Дата «сегодня» берётся из `meta.as_of_date`, а не из часов компьютера.

## Технологии и архитектура

Python 3.12, uv, Pydantic, Streamlit, pandas, structlog; Ruff, mypy и pytest для проверок.
Пакет собирается Hatchling. GitHub Actions запускает проверки при push и PR.

- `career_quest/models.py` — схема стартового кита.
- `career_quest/ingestion.py` — импорт и валидация связанных файлов.
- `career_quest/progress.py` — текущие навыки, завершение и экспорт.
- `career_quest/recommendations.py` — расчёт дефицитов и ранжирование.
- `career_quest/demo.py` — собственные синтетические примеры.
- `tests/` — проверка поведения без доступа к данным организаторов.

## Ограничения

Это локальный прототип. Подтверждение завершения учебной системой, HR-интеграции,
разграничение доступа и AI-рекомендации не реализованы. Подбор не гарантирует повышение.
Ссылка на развёрнутую версию отсутствует.
